# Update Documentation

Read through the docs and then the entire codebase and make sure that the docs are up to date. Add any new relevant information to the documentation and remove old documentation that is no longer relevant.

## Process

### 1. Read the documentation

Go into /.claude/docs and read all the documentation, if none exists, make the folder and continue to step 2.

### 2. Explore the codebase

- Understand the architecture and layout of the codebase
- Where are the different functionalities found?
- Look for crital information needed when working on the code
- What are the most important functions and files
- What is important that stays as is
- What does a developer need to know when creating new code and functionalities

### 3. Write the documentation

- Create or update the existing documentation with all the important informatio n you found in the last step
- Make the documentation structured, if more than ~100 lines, it should be split into separate files covering different topics

### 4. Remove outdated information

- Go over the documentation and make sure there are no outdated or uneccesary information there, if there is, remove
- The docs should be compact enough so that it's easy to use
